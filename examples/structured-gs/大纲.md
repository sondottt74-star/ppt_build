# 结构化 3D Gaussian Splatting：从 Anchor 到 LOD 与遮挡先验

> 副标题：Scaffold-GS（CVPR 2024）· Octree-GS · Proxy-GS
>
> 共 35 页（含 3 张章节页），约 22 分钟：开场 2 分钟，三篇各约 6–7 分钟，总结 1–2 分钟。
>
> 版式、画法和代码结构沿用范本 [sondottt74-star/ppt_build](https://github.com/sondottt74-star/ppt_build)（`make_assets.py` + `build_ppt.py`）。第 0 部分是全局制作规范，后面每一页都写了“讲什么”和“怎么做”。

## 主线：什么是结构化高斯

普通 3DGS 直接优化一大堆彼此独立的 Gaussian。**结构化高斯**先在空间里建一个结构（anchor），再由这个结构通过共享 MLP 生成 Gaussian。

| 论文 | 结构是什么样 | 这一篇加了什么 |
|---|---|---|
| Scaffold-GS | 单层 anchor | 提出结构化高斯：anchor 组织 Gaussian，共享 MLP 生成属性 |
| Octree-GS | 多层 anchor（八叉树） | 结构有了层级，远处用粗层，近处加细层 |
| Proxy-GS | 多层 anchor + 粗几何 | 结构知道遮挡，被挡住的 anchor 提前跳过 |

贯穿全场的例子是**同一栋建筑**：换一个角度看它（Scaffold-GS），从远处走近它（Octree-GS），它被前面的楼挡住（Proxy-GS）。每篇按“改了什么 → 为什么 → 方法 → 实验 → 局限”讲，前一篇的局限就是下一篇的动机。

## 0.6 素材规则（`make_assets.py`）

**论文原图直接用。** PDF 用 `fitz.open(pdf)[0].get_pixmap(dpi, alpha=False)` 转 PNG，再用范本的 `trim()` 裁白边。默认 `dpi = 260`，但 Octree 的 `Teaser/LODBias/LargeScale` 这类页面很宽的 PDF 要限制像素宽：`dpi = min(260, 3000·72 / rect.width)`。论文本来就是 PNG 的（`framework.png`、`vis_1901.png`、`anchors.png` 等）用 PIL 直接 `convert("RGB").save`。文件名加前缀：`sc_` Scaffold，`oc_` Octree，`px_` Proxy。

**公式统一渲染成透明 PNG。** 照抄 `render_formulas()`：`fig.text(0, 0, tex, fontsize=30)`，`dpi = 250`，`bbox_inches="tight"`，`transparent=True`。mathtext 不支持 `\operatorname`、`\text` 和中文：用 `\mathrm{}` 代替，中文写在旁边的文本框里。

**示意图用 matplotlib 自绘。** 沿用范本的 `draw_blob()`（多层半透明椭圆画 Gaussian）、`View` 正交投影类（画伪 3D）、`FancyArrowPatch` 箭头；`ax.axis("off")`，`dpi = 220`，透明背景。图里的中文 13–17 号。

### P18 当前相机选哪几层

**讲什么：**

\[
L^*=\Phi\left(\log_2\frac{\hat d_{\max}}{d\cdot s}\right)+\Delta L,\qquad \hat L=\lfloor L^*\rfloor .
\]

- \(d\)：越远，层号越小，越粗；\(s\)：焦距、分辨率修正；\(\Phi\)：限制在 0 到 \(K-1\)；\(\Delta L\)：每个 anchor 自己学的偏置，栏杆比平墙多给一点细节。
- 选中规则：anchor 所在层 \(\le\hat L\)。
- 例子：\(\hat d_{\max}=16,\ s=1,\ \Delta L=0\)：距离 8 用到第 1 层，距离 4 用到第 2 层，距离 2 用到第 3 层。
- 重点：没选中的 anchor 不进 MLP。

**怎么做：** 版式 C。

### P27 训练时也要用同一套规则

**讲什么：**

- 训练推理一致：训练时被挡住的 anchor 也不参与，否则测试时突然删掉会缺一块。
- 新 anchor 长在表面上：原来梯度大就加 anchor，楼后面也可能梯度大，加上去永远过不了遮挡测试。改成：找误差大的图像区域 → 用 proxy 深度找到对应表面 → 在表面附近加 anchor → 同一格不重复加。

**怎么做：** 左对照卡，右示意图。

### P30 局限

**讲什么：**

1. proxy 不准会误删：位置偏了、前后关系错了，可见物体会被切掉；室内无纹理时网格本身可能不可靠。
2. 一张深度图表达不了半透明：玻璃、树叶、栅栏。
3. 遮挡少的场景收益小，画深度和测试的开销可能抵消节省。
4. 需要额外准备几何：生成、简化、对齐网格。
